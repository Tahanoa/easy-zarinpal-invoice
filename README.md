# Easy Invoice for ZarinPal

<img width="1536" height="1024" alt="hirosection" src="https://github.com/user-attachments/assets/fe6b695a-329d-4a1a-9520-fe4b33034da9" />


A modern WordPress invoice and payment link plugin with ZarinPal gateway integration and WooCommerce support.

Create custom invoices, generate payment links, add WooCommerce products, calculate shipping costs, and receive online payments easily.

## ✨ Features

- Create custom payment invoices from WordPress admin panel
- Generate unique payment links for customers
- ZarinPal payment gateway integration
- WooCommerce product search and selection
- Add multiple products to invoices
- Automatic calculation of product totals
- Fixed shipping cost support
- Custom invoice page using WordPress shortcode
- Fully compatible with WordPress themes
- Mobile-friendly invoice design
- Secure payment verification
- Transaction status management
- Lightweight and optimized code

## 🚀 Installation

1. Download the latest plugin version:

[Download Easy ZarinPal Invoice v1.4.0](https://github.com/Tahanoa/easy-zarinpal-invoice/releases/download/v1.4.0/easy-zarinpal-invoice-v1.4.0.zip)

2. Go to:

```
WordPress Dashboard → Plugins → Add New → Upload Plugin
```

3. Upload the ZIP file and activate the plugin.

4. Configure your ZarinPal Merchant ID from plugin settings.

## ⚙️ Configuration

After activation:

1. Open plugin settings
2. Enter your ZarinPal Merchant ID
3. Create an invoice page
4. Add the shortcode:

```
[ezi_invoice]
```

5. Use this page as your customer payment page.

## 🛒 WooCommerce Support

Easy ZarinPal Invoice allows you to:

- Search WooCommerce products
- Add products to invoices
- Select quantity
- Calculate product prices automatically
- Add fixed shipping costs

Product prices are stored when the invoice is created to keep invoice amounts consistent.

## 💳 Payment Gateway

This plugin uses ZarinPal payment gateway.

Supported features:

- Payment request
- Redirect to ZarinPal gateway
- Payment verification
- Transaction tracking

## 📌 Requirements

- WordPress 6.x+
- PHP 7.4+
- WooCommerce (optional, for product invoices)
- Active ZarinPal merchant account

## 📝 Shortcode

Display invoice payment page:

```
[ezi_invoice]
```
